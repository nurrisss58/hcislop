# NAir High — GitHub Pages

This version is prepared for a **flat GitHub repository**. All HTML, CSS, JavaScript and image files are in the repository root so GitHub Pages can serve them directly.

## Publish
1. Upload all files from this folder to the root of your GitHub repository.
2. In **Settings → Pages**, select **Deploy from a branch**, choose your main branch and `/ (root)`.
3. Open the generated GitHub Pages URL.

## Pages
- index.html — Home
- destinations.html — Destinations
- search.html — Search results
- booking.html — Booking
- fleet.html — Fleet
- about.html — About
- contact.html — Contact
- faq.html — FAQ

This is a front-end prototype. Login, booking submission and search are demo interactions and do not connect to a backend or payment service.
